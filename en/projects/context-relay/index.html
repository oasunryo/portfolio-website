Context Relay: Zero-Loss Handover System for AI Coding Assistants

1) Project Overview

  • Period: 2026. 06. 15. ~ 2026. 06. 16.
  • Type: Prompt Engineering & AI Agent Token Optimization Tool
  • Organization: Personal Open Source Initiative
  • Description: A framework-agnostic system prompt workflow designed to bypass token accumulation, eliminate latency drift, and perform zero-loss task handovers.

2) Background & Problem Definition

  • Background: Relying heavily on AI coding agents (Cursor, Cline, Claude Code) over hours of development inflates active context sizes up to 50K - 150K tokens due to tracebacks, terminal output, and redundant file scans.
  • Problem Statement:
    • High active context increases Time-to-First-Token (TTFT) response latency above 10 seconds and inflates token billing dynamically.
    • LLM attention spreads thin over historical logs, leading to model drift and visual code hallucination.

3) Objectives

  • Token Reduction: Shrink active conversational window by up to 98% (e.g. 50K tokens down to 1.5K tokens) by purging redundant session logs.
  • Latency recovery: Reclaim sub-second response times by resetting model memory.
  • Precision Continuity: Re-align new chat instances with structured, lossless task states.

6) Implementation Steps

Step 1: Noise Purging

Discard dead-end debugging loops, stdout outputs, and compiler errors from the model's history.

Step 2: Workspace State Auditing

Structure ongoing code diffs, file modifications, and current task lists (task.md) into a compact serialized markdown string.

Step 3: Transfer Prompt Generation

Instruct the agent to compile this data into a highly structured, copy-pasteable handover block designed to instantly align the subsequent session.

11) One-Command Installation

Run install.sh from the GitHub repo to automatically apply Context Relay to your preferred AI agent:

# One-command install
curl -sL https://raw.githubusercontent.com/oasunryo/context-relay/main/install.sh | bash

# Installation targets:
# 1) Antigravity Custom Skill  (~/.gemini/antigravity/...)
# 2) Cursor Rules              (project root .cursorrules)
# 3) Roo Code / Cline         (project root .roo/instructions)
