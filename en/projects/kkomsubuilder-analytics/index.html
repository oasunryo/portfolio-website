(Career hacking content creation for semiconductor job seekers, shorts/carousel automation pipeline, and Meta data analytics)

1) Project Overview

  • Period: 2026. 06. 01. ~ Present (Active)
  • Type: IT/Semiconductor Tech Creator Channel Branding & Data Pipeline
  • Channel Name: 'Kkomsubuilder' (@kkomsubuilder)
  • Summary: Built a tech creator channel providing actionable career hacking tips, JD analysis, and fab data methodologies for semiconductor job seekers, backed by an automated performance analytics pipeline.

2) Background & Objectives

  • Background: Designed to solve the common issue where job applicants fail screening due to generic resume descriptions, by teaching them how to link fab data (Kaggle SECOM, Spotfire) and JD specs to actual GitHub projects.
  • Core Objectives:
    • Content Main Strategy: Deliver tailored short-form clips and Instagram carousel posts covering semiconductor process job analyses, portfolio differentiation, and GitHub project management.
    • Analytics Automation: Replace manual logging with a Python pipeline that converts Meta metrics (PDT -> KST) and auto-syncs performance to a Google Sheets dashboard.

3) Key Performance Metrics

  • Viral Breakout: Achieved 30,345 Reach, 591 Saves, 208 Shares, and +33 New Followers on a single post about fab data resume tips.
  • User Behavior Pattern (KST Calibrated):
    • 10:00 AM KST (Educational Content): 4x higher Save rate (Avg 10.1 saves/post) as users bookmark guides for studying.
    • 10:00 PM KST (Hiring News): High Share and Reach (Avg 663 reach, 4.1 shares) as users pass news to peers.

4) Tech Stack & Pipeline

Category Details
Content Creation CapCut 9:16 Shorts Generator, Python Draft Builder, Figma Carousel Automation
Data Pipeline Python, Pandas, Meta Graph API Exporter, KST Timezone Calibration Engine
Auto Sync Google Sheets API (gspread), Content Performance Automation Dashboard
Domain Topics JD Analytics, Semiconductor Fab Data (Spotfire/Kaggle SECOM), GitHub Portfolio Branding

5) Implementation Steps

1. Tailored Content Branding & Pipelines

Established the 'Kkomsubuilder' identity. Developed automated rendering scripts to slice long-form presentations into 10 CapCut short-form drafts (Shorts/Reels).

2. KST Timezone Calibration Engine (`sync_meta_performance_to_sheets.py`)

Converted Meta export CSV timestamps from PDT to KST (+16h), accurately mapping user engagement windows with upload time slots.

3. Automated Google Sheets Dashboard Sync

Integrated performance metrics directly into the Google Sheets 'Creator Content Calendar', updating visual guideline tabs automatically.

6) Lessons Learned

Learned how to transform complex technical domain data into engaging, accessible storytelling for target audiences while establishing a data-driven creator growth workflow powered by automated analytics pipelines.

How similarity is calculated

Recommended content on this portfolio is sorted based on the Cosine Similarity between multi-dimensional text embedding vectors extracted using the Google Gemini API (gemini-embedding-2 model).

By analyzing the title, category, description, and full body text, it evaluates semantic relevance beyond simple keyword matching. If the API is unavailable, it automatically falls back to a local TF-IDF term frequency analysis algorithm.
