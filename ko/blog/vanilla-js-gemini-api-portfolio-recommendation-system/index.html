프레임워크 없이 순수 쌩 코딩으로 포트폴리오를 만드는 이유

React나 Next.js는 훌륭하지만, 개인 포트폴리오 웹사이트에서는 잦은 라이브러리 업데이트와 용량 최적화 문제가 생깁니다. HTML5, Vanilla CSS, Pure ES6+ JS만을 사용하여 로딩 속도가 극도로 빠르고 가벼운 정적 포트폴리오 웹사이트를 구축했습니다.

Gemini Embeddings 기반 연관 추천 엔진 구현

  • Gemini API 활용: 빌드 타임(build.js)에 각 포스트 본문 텍스트의 768차원 다차원 임베딩 벡터를 추출.
  • Cosine Similarity 연산: 두 글 간의 임베딩 벡터 코사인 유사도를 계산하여 가장 관련 깊은 포스트 상위 3개를 자동 매칭.
  • Rate Limit 극복 및 Caching: 650ms 호출 딜레이와 파일 시스템 Caching을 통해 API 제한 극복 및 빌드 100% 성공율 달성.
  • TF-IDF Fallback: API 미연결 시 로컬 TF-IDF 연산으로 자동 전환되는 회복성 확보.

연관도 계산 방식 알아보기

본 포트폴리오의 추천 콘텐츠는 Google Gemini API(gemini-embedding-2 모델)를 활용해 추출한 다차원 텍스트 임베딩 벡터 간의 코사인 유사도(Cosine Similarity)를 기준으로 정렬됩니다.

글의 제목, 카테고리, 요약 설명 및 전체 본문을 종합 분석하여 단순한 키워드 일치를 넘어선 의미론적 연관성(Semantic Similarity)을 판별합니다. API 호출이 불가한 환경에서는 로컬 TF-IDF 기반의 단어 빈도 분석 알고리즘으로 자동 전환(Fallback)되어 연관도를 계산합니다.
