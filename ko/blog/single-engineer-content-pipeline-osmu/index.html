시간이 부족한 엔지니어를 위한 One Source Multi-Use (OSMU)

현직 엔지니어나 취업준비생 모두 학업과 업무로 시간이 절대적으로 부족합니다. 세컨드 브레인에 기록한 기술 메모 1개를 다양한 소셜 채널 및 포트폴리오 자산으로 즉시 변환하는 콘텐츠 파이프라인 시스템이 구축되어야 지속 가능한 퍼스널 브랜딩이 가능합니다.

콘텐츠 생산 파이프라인 4단계 릴레이

  • 1단계 (Source Markdown): Obsidian에 FC-BGA Warpage 메커니즘 노트를 요약 정리 (핵심 개념 + 원인 + 해결책).
  • 2단계 (Portfolio Blog): Node.js 빌더로 마크다운을 JSON 변환하여 개인 정적 사이트 포스트로 상시 게시.
  • 3단계 (LinkedIn Pulse & Post): 서술형 블로그 문장을 가독성 높은 3줄 요약 bullet point 형태의 링크드인 인사이팅 아티클로 재구성.
  • 4단계 (Shorts/Reels Script): "FC-BGA 휨 현상 1분 만에 이해하기" 형태의 자극적인 후킹 문장과 CapCut 대본으로 전환하여 비디오 제작.

시스템이 가져다주는 선순환 효과

하나의 공부가 4개의 디지털 자산으로 변환되어 면접관에게는 전문성을, 인맥 네트워크에는 기술적 영향력을 동시에 전달하는 강력한 브랜딩 선순환 구조를 만들어 냅니다.

연관도 계산 방식 알아보기

본 포트폴리오의 추천 콘텐츠는 Google Gemini API(gemini-embedding-2 모델)를 활용해 추출한 다차원 텍스트 임베딩 벡터 간의 코사인 유사도(Cosine Similarity)를 기준으로 정렬됩니다.

글의 제목, 카테고리, 요약 설명 및 전체 본문을 종합 분석하여 단순한 키워드 일치를 넘어선 의미론적 연관성(Semantic Similarity)을 판별합니다. API 호출이 불가한 환경에서는 로컬 TF-IDF 기반의 단어 빈도 분석 알고리즘으로 자동 전환(Fallback)되어 연관도를 계산합니다.
